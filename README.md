# Recipe Project - CS:3910
## Season by Season

A web application that helps users discover recipes based on ingredients that are currently in season. Instead of browsing through generic recipe lists, users can filter results by zipcode or by season to find meals that align with locally available produce.

The application also allows users to filter out specific food allergies, creating a more accessible experience.

---

## Features

### Seasonal Filtering
- Search by zipcode to identify seasonal ingredients in a specific area
- Filter directly by season (Spring, Summer, Fall, Winter)
- View recipes that match seasonal availability

### Allergy Filtering
- Exclude common allergens from recipe results
- Improve accessibility for users with dietary restrictions

### Recipe Tags
- Results page displays tags for:
    - Seasonal alignment
    - Allergy information

### Detailed Recipe Page
Each recipe page includes:
- A description
- A complete ingredient list
- Step-by-step cooking instructions 
- A map displaying nearby farmers markets and local vendors
    - Shows where users can purchase the fresh ingredients
- A built-in print button for offline access
